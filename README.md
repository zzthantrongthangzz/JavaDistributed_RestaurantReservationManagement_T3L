# Java Distributed Restaurant Reservation Management

> **Legacy academic project — archived development line**

This repository is the distributed evolution of the original Java Swing restaurant-management project. It uses a Java client/server structure, Java RMI-style communication, and Neo4j.

The repository is preserved as historical evidence and as a source for business-rule and migration research. It is no longer the active product codebase.

## Active successor

New development continues in [CulinaOps Restaurant Platform](https://github.com/zzthantrongthangzz/culinaops-restaurant-platform), a production-oriented web platform using Java, Spring Boot, PostgreSQL, Next.js, Docker, Terraform, and AWS.

## Preservation rules

- Do not add new product features here.
